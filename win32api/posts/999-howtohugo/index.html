999-HowToHugo

Windows に Hugo をインストールし、GitHub Pages にサイトを作るまでの手順。

方法は2つある

Hugo で GitHub Pages を作る方法は2つある。

  • ローカルの Hugo でページを作り、GitHub Pages に push する。
  • GitHub に Markdown を push するとサーバー側の Hugo がページを更新。

今回はローカルで HTML を作る方法にした。
手元でデバッグとか校正したページを公開したいですからね。

関連ツールのインストール

  1. Hugo をインストールする。winget を使うと簡単である。 
    winget install Hugo.Hugo.Extended
  2. git コマンド も必要。
    まだ入れてなければ Git for Windows がおすすめ。
  3. テキストエディタも必要。
    VS Code とか NotePad++ とか、お好みで。

プロジェクトの作成とテーマの設定

  1. サイト単位で Hugo のプロジェクトを作成する。
    ここでは win32api-progs というプロジェクト名にしてみた。
    プロジェクトが完成すると、フォルダが作られるので、そこに移動する。 
    hugo new site win32api-progs
cd win32api-progs
  2. 設定ファイルを用意する。
    プロジェクトのルートに hugo.toml という設定ファイルを作る。 
    # ./hugo.toml
baseURL = 'https://doc.yuimax.org/win32api/'
title = 'win32api-progs'
  3. 画面テーマをインストールする。
    git init でプロジェクトをリポジトリ化し、git submodule でテーマを入れる。
    今回は Mainroad というテーマを選んだ。サイドバーが作りやすいらしい。 
    git init
git submodule add https://github.com/vimux/mainroad.git themes/mainroad
  4. 設定ファイルにテーマを登録する。
    hugo.toml にテーマ名と言語設定を追加する。 
    theme = 'mainroad'
locale = 'ja-jp'
defaultContentLanguage = 'ja'

レンダーフックのインストール

レンダーフックとは、Hugo に機能を追加するプラグインのようなものである。
現在は次のレンダーフックを登録している。

  • コードブロックに COPY ボタンを追加
  • 画像タグにサイズ指定機能を追加

コードブロックに COPY ボタンを追加

  1. ファイル layouts/_default/_markup/render-codeblock.html を作り下記を設定する。

    <div class="code-block-wrapper">
  <div class="code-block-header">
	<span class="code-lang">{{ .Type | default "text" }}</span>
	<button class="copy-button" aria-label="Copy code">Copy</button>
  </div>
  <pre><code class="language-{{ .Type }}">{{ .Inner }}</code></pre>
</div>

  2. CSS を追加する。

    .code-block-wrapper {
  position: relative;
  margin: 1em 0;
  border-radius: 6px;
  overflow: hidden;
  background: #282c34; /* 使用中のテーマに合わせて調整 */
}

.code-block-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  background: #21252b;
  padding: 0.4rem 0.8rem;
  font-size: 0.85rem;
  color: #abb2bf;
}

.copy-button {
  background: #3e4451;
  color: #fff;
  border: none;
  border-radius: 4px;
  padding: 0.2rem 0.6rem;
  cursor: pointer;
  font-size: 0.8rem;
  transition: background 0.2s;
}

.copy-button:hover {
  background: #4b5263;
}

.copy-button.copied {
  background: #98c379;
  color: #1e1e1e;
}

  3. ファイル baseof.html の末尾に次の JavaScript を追加する。

    document.addEventListener('DOMContentLoaded', () => {
  document.querySelectorAll('.copy-button').forEach(button => {
	button.addEventListener('click', async () => {
	  const wrapper = button.closest('.code-block-wrapper');
	  const code = wrapper.querySelector('code').innerText;

	  try {
		await navigator.clipboard.writeText(code);

		// フィードバック表示の変更
		const originalText = button.textContent;
		button.textContent = 'Copied!';
		button.classList.add('copied');

		setTimeout(() => {
		  button.textContent = originalText;
		  button.classList.remove('copied');
		}, 2000);
	  } catch (err) {
		console.error('Failed to copy: ', err);
	  }
	});
  });
});
