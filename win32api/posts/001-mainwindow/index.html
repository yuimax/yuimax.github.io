ウィンドウクラスの登録

すべてのウィンドウは ウィンドウクラス に属している。 たとえば BUTTON や EDIT など既存の GUI 部品も、専用のウィンドウクラスを利用することで、それぞれの動作を実現している。

  • 解説＞ ウィンドウクラスについて 【英語版 】
  • 解説＞ ウィンドウクラスの利用 【英語版 】
  • 解説＞ ウィンドウクラス仕様書 【英語版 】

自作アプリのメインウィンドウは、まず自分のウィンドウクラスを登録する必要がある。

コード

ウィンドウクラスを登録する部分のコードを次に示す。 WNDCLASSEX 構造体でパラメータを設定し、RegisterClassEx() で実際に登録する。

WNDCLASSEX wcex = { sizeof(WNDCLASSEX) }; // 先頭要素のみ指定、残りを0で埋める

wcex.style = CS_HREDRAW | CS_VREDRAW; // (1)
wcex.lpfnWndProc = WndProc;           // (2)
wcex.hInstance = hInstance;           // (3)
wcex.lpszClassName = WindowClassName; // (4)

return RegisterClassEx(&wcex);

(1) wcex.style

下記のスタイルを組み合わせて指定する。 その他のスタイル もあるが、どれも Windows XP 以前のレガシーであり、現代のマシンではまあ不用といってよい。

  • CS_HREDRAW
    幅が変更されたら画面を再描画する。
  • CS_VREDRAW
    高さが変更されたら画面を再描画する。
  • CS_DBLCLKS
    ダブルクリックを検出できるようにする。
  • CS_NOCLOSE
    タイトルバーの「×」ボタン、システムメニューの「閉じる(C)」、Alt+F4 キーによるアプリ終了を禁止する。

(2) wcex.lpfnWndProc

各種ウィンドウメッセージを処理するための関数。 ここではソースコード内の WndProc() 関数を指定している。 関数名はなんでもよいが、慣例として WndProc という名前を使う。

(3) wcex.hInstance

実行中のアプリ自身を示すハンドルを指定する。 これを登録することで、システムがアプリの内部データにアクセスしたり、複数起動した同じアプリを識別できるようになる。

(4) wcex.lpszClassName

メインウィンドウが使うウィンドウクラスの名前。 同じプロジェクトの中で別のウィンドウと重複しなければ、なんでもよい。

上記以外のメンバ

他にもいろいろあるが、今後プログラムで必要になったとき説明を書く。

ウィンドウの作成

ウィンドウは Win32API の CreateWindowEx で作成する。

Win32API の A 型と W 型について

Win32API には、A 型と W 型が存在する場合がある。 CreateWindowEx も CreateWindowExA と、CreateWindowExW の2つがある。

両者の違いは文字列引数の文字コードである。

  • A 型は、文字列引数を Shift_JIS の 通常文字列（例："テスト"）で指定する。
  • W 型は、文字列引数を UTF-16LE のワイド文字列（例： L"テスト"）で指定する。

最近のソースコードは UTF-8 で書かれることが多いため、Shift_JIS を要求する A 型の API は使いにくい。 そこで Visual C++ では、デフォルトで W 型の API を使うようになっている。

たとえばソースコードに CreateWindowEx と書くと、実際には CreateWindowExW が呼び出される。 これに準じて本サイトでは、API が本来 W 型でも名前の最後に “W” をつけない。

コード

HWND hWnd = CreateWindowEx(
  0,                    // (1) dwExStyle
  WindowClassName,      // (2) lpClassName
  WindowTitle,          // (3) lpWindowName
  WS_OVERLAPPEDWINDOW,  // (4) dwStyle
  CW_USEDEFAULT,        // (5) X
  CW_USEDEFAULT,        // (6) Y
  INIT_WINDOW_WIDTH,    // (7) nWidth
  INIT_WINDOW_HEIGHT,   // (8) nHeight
  nullptr,              // (9) hWndParent
  nullptr,              // (10) hMenu
  hInstance,            // (11) hInstance
  nullptr               // (12) lpParam
);
