ウィンドウクラスの登録

すべてのウィンドウは ウィンドウクラス に属している。 たとえば BUTTON や EDIT など既存の GUI 部品も、専用のウィンドウクラスを利用することで、それぞれの動作を実現している。

  • 解説＞ ウィンドウクラスについて 【英語版 】
  • 解説＞ ウィンドウクラスの利用 【英語版 】
  • 解説＞ ウィンドウクラス仕様書 【英語版 】

自作アプリのメインウィンドウは、まず自分のウィンドウクラスを登録する必要がある。

コード

ウィンドウクラスを登録する部分のコードを次に示す。
WNDCLASSEX 構造体でパラメータを設定し、RegisterClassEx() で実際に登録する。

WNDCLASSEX wcex = { sizeof(WNDCLASSEX) }; // 先頭要素のみ指定、残りを0で埋める

wcex.style = CS_HREDRAW | CS_VREDRAW; // (1)
wcex.lpfnWndProc = WndProc;           // (2)
wcex.hInstance = hInstance;           // (3)
wcex.lpszClassName = WindowClassName; // (4)

return RegisterClassEx(&wcex);

(1) wcex.style

下記のスタイルを組み合わせて指定する。 その他のスタイル もあるが、どれも Windows XP 以前のレガシーであり、現代のマシンではまあ不用といってよい。

999-HowToHugo

Windows に Hugo をインストールし、GitHub Pages にサイトを作るまでの手順。

方法は2つある

Hugo で GitHub Pages を作る方法は2つある。

  • ローカルの Hugo でページを作り、GitHub Pages に push する。
  • GitHub に Markdown を push するとサーバー側の Hugo がページを更新。

今回はローカルで HTML を作る方法にした。
手元でデバッグとか校正したページを公開したいですからね。

関連ツールのインストール

  1. Hugo をインストールする。winget を使うと簡単である。 
    winget install Hugo.Hugo.Extended
  2. git コマンド も必要。
    まだ入れてなければ Git for Windows がおすすめ。
  3. テキストエディタも必要。
    VS Code とか NotePad++ とか、お好みで。

プロジェクトの作成とテーマの設定

  1. サイト単位で Hugo のプロジェクトを作成する。
    ここでは win32api-progs というプロジェクト名にしてみた。
    プロジェクトが完成すると、フォルダが作られるので、そこに移動する。 
    hugo new site win32api-progs
cd win32api-progs
  2. 設定ファイルを用意する。
    プロジェクトのルートに hugo.toml という設定ファイルを作る。 
    # ./hugo.toml
baseURL = 'https://doc.yuimax.org/win32api/'
title = 'win32api-progs'
  3. 画面テーマをインストールする。
    git init でプロジェクトをリポジトリ化し、git submodule でテーマを入れる。
    今回は Mainroad というテーマを選んだ。サイドバーが作りやすいらしい。 
    git init
git submodule add https://github.com/vimux/mainroad.git themes/mainroad
  4. 設定ファイルにテーマを登録する。
    hugo.toml にテーマ名と言語設定を追加する。 
    theme = 'mainroad'
locale = 'ja-jp'
defaultContentLanguage = 'ja'
